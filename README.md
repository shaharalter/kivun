# כיוון – הכוונה ללימודים, קבלה וחיי סטודנט

אתר שעוזר לבחור תואר ומוסד: שאלון הכוונה (מודל הולנד), בדיקת סיכויי קבלה לפי ציוני בגרות ופסיכומטרי, השוואת עלויות, מגורים, מלגות ואנשי קשר – לשנת תשפ״ז.

## הקבצים

| קובץ | מה זה |
|---|---|
| `index.html` | האפליקציה: עמוד פתיחה, שאלון, תוצאות ועמוד לכל תואר |
| `data.html` | מאגר הנתונים: תארים, מוסדות, אנשי קשר, עלויות מחיה, מלגות, מעונות |
| `MAAGAR.md` | כל הנתונים בטבלאות + הסבר מלא על האתר |

## עדכון האתר

מחליפים את הקובץ המתאים (העלאה מחדש עם אותו שם) – והאתר מתעדכן תוך דקה–שתיים.

## הערה

הנתונים נאספו ממקורות רשמיים וממאגרים מוכרים, ולכל פרט מצוין מקור. חלק מהחישובים הם הערכות – יש לאמת מול המוסדות לפני הגשה.
